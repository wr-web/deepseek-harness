# Agent Note：已完成轮次上下文图与有界复用

Status: implemented

[English](2026-08-26-context-graph-recall.md) | 中文

## Problem

彼此独立的会话会反复为同一项目定位、代码搜索和解释付出 token。用户已经知道有用来源和序列时，会话 fork 可以保留准确前缀；会话引用则复制用户选定的来源。这两种机制都不会为新请求发现相关的已完成轮次，也不会展示可复用工作在多个项目和 fork 之间的关系。

把隐藏模型 reasoning 当作持久记忆会暴露产品原本不投影的内容，依赖提供方是否提供 reasoning，还会鼓励重放旧任务中的指令。自动复制完整会话也会为无关历史付出 token，并使过期上下文更难识别。

## Decision

`@deepseek-ai/dsh-context-graph` 从持久会话事件派生有界森林，不新增存储格式。每个可复用节点是一个已完成轮次，由会话 ID、轮次和终止序列标识。prompt 使用直接用户文本，key 与摘要使用可见的 assistant 最终文本，action 统计已记录工具调用。reasoning 块、未完成轮次和继承的 seed 事件会被排除。提供方用量保留在各节点上用于计量。

连续边和会话 fork 边组成结构森林。工作目录提供初始项目根。自动复用的节点会产生独立复用边，该边从带身份的 `user/message` source 重建。复用记录携带源节点/会话 ID、捕获序列、匹配分数和准确 UTF-8 字节，因此重放不依赖可变的外部索引。

web 配置只在全新根会话的第一个 step 自动复用。确定性词法匹配覆盖 prompt、可见摘要和工具名，支持中文字符与双字组合，要求记录的工作目录相同，并排除已腐败节点。系统最多追加一个完整检查点，限制为 2048 字节。它被标记为不可信、只读背景；元数据无法放入上限时会跳过该候选。插件使用 `agent/pre-step` 与 session-query 服务，而不修改 `agent-loop`。

新鲜度是年龄分类。web 使用 30 天期限，把节点分为新鲜、老化中与已腐败；已腐败节点仍可查看，但不能自动复用。这种分类能阻止无限期静默复用，但不会假装已经验证项目文件。

`@deepseek-ai/dsh-client-ui-context-graph` 注册会话视图，并把已完成轮次呈现为圆形节点。连续轮次共享一条竖直轨道；同级 fork 在父节点的下一层占用紧凑轨道。复用使用不影响结构位置的虚线。选择节点后，检查面板显示请求、可见结论、工具、token 总量、来源和准确边界 fork 操作。自动复用向当前根会话提供检查点；它有意与显式会话 fork 区分，后者会继承选定前缀。

Web profile 把 Host 包与浏览器包作为一项功能挂载。两个包都属于共享的 `dsh-v*` release family，并以运行中的 DSH 版本发布。它们不会再组成一个可选 Profile Bundle：只安装或移除其中一半无法得到可用功能，而在 Web 上叠加组合包会重复 Web 已拥有的配置项。

公开评测 helper 从基线与复用会话日志汇总真实提供方用量，报告未缓存输入节省、总输入节省、下降比例、输出差值、复用次数和注入字节。产品评测应把这些成本数据与独立的任务成功、改动、测试和延迟检查配对。

## Alternatives considered

**把隐藏 `think` 文本持久化为节点。** 拒绝，因为隐藏 reasoning 不是稳定的公开模型输出，可能包含敏感或误导性的中间内容。可见的完成回答可以提供可重放检查点，而不会建立 chain-of-thought 档案。

**为每个轮次调用模型生成新摘要。** 首版拒绝，因为它会增加本功能试图减少的 token 成本，并引入另一个依赖提供方的失败路径。未来 summarizer 可以成为显式 provider，而可见文本仍是持久来源。

**匹配后自动 fork 当前会话。** 拒绝，因为 pre-step 匹配运行时新会话已经存在，替换其 Agent/会话身份会干扰 inbox、RPC 和生命周期归属。有界复用负责自动发现；准确 fork 保持为显式会话操作。

**立即使用语义 embedding。** 不作为必需基础，因为它会增加存储、模型选择、失效和凭据问题。确定性词法排序提供无密钥基线，并保持排序可替换。

**存储独立图数据库。** 拒绝，因为会话 header 和事件已经拥有全部所需事实。由事件失效的派生缓存不会与持久日志漂移，也不需要 schema migration。

**隐藏老节点。** 拒绝，因为年龄不能证明内容无效。已腐败节点仍适合检查和显式 fork，而自动复用保持保守。

**发布可单独安装的 context-graph 组合包。** 拒绝，因为浏览器包与 Host 包互相依赖，且 Web profile 已拥有两者的配置项。第二个组合包无法形成可独立使用的组合，反而会让安装与移除语义产生误导。

## Verification

纯图测试覆盖继承事件排除、连续/fork/复用边、准确复用字节、英文与中文匹配、工作区亲和、腐败排除、提供方 token 投影、UTF-8 截断和基线对比。服务测试挂载真实 Session Store 与 Session Query Engine，运行 `agent/pre-step` waterfall，验证一次有界首 step 复用，确认隐藏 reasoning 不会出现，并覆盖元数据无法装入上限的情况。客户端 layout 测试覆盖父节点相对行、紧凑的同级 fork、复用边不影响结构位置和异常循环。无密钥快照通过真实 Loader 配置启动两个全新根会话；如果目标 adapter 没有收到带日志来源且不含私有 reasoning 的源检查点，请求会直接失败。Host 与 Client TypeScript face 均可编译，Typert 会生成 `snapshot` 与 `match` 远端客户端，相关包可定向打包。

## Consequences

新的根任务可以复用一小段有日志来源的检查点，而不用携带整段旧对话。用户可以检查分支来源，并从任何保留的完成轮次 fork。此功能随标准 Web profile 提供，不能通过单独安装而与 DSH 包版本产生偏差。有界扫描与词法分数具有可预测的无密钥成本，但可能漏掉语义改写或选中偶然词汇匹配。按年龄腐败可以抑制旧上下文，却无法识别仓库 revision；Git/文件指纹与语义排序仍适合后续 provider。

token 节省是实验结果，不是设计保证。复用会消耗有界 suffix，只有它替代的重复工作多于新增内容时才会节省。评测 helper 让这个权衡可计量，同时把任务质量判断留给拥有该任务的 benchmark。
